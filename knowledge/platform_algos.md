## X / TWITTER ALGORITHM

### What the Algorithm Rewards
- **Engagement rate** (likes + replies + reposts) in first 30-60 min after posting
- **Reply engagement** — conversations in replies boost reach significantly
- **Quote tweets with commentary** > plain retweets
- **Saves/bookmarks** signal high-value content
- **Follower-to-impression ratio** — high ratio = algorithm trusts you
- **Fresh followers gained from post** signals quality to algo

### What Destroys Reach
- Posting links (algorithm suppresses link posts vs text)
- Excessive @mentions or #hashtags
- Low engagement in first 2 hours (algo kills it fast)
- Posting too frequently (flood penalty — "spammy" signal)
- Low reply rate (algorithm wants conversation, not broadcast)

### Optimal Posting Windows (AWST)
| Day | Best Times |
|-----|-----------|
| Monday | 7-9am, 12-1pm, 5-6pm |
| Tuesday | 7-9am, 12pm, 5-7pm |
| Wednesday | 7-9am, 12pm, 5-6pm |
| Thursday | 7-9am, 12pm, 5-7pm (peak day) |
| Friday | 7-9am, 12pm (lower — weekend prep) |
| Saturday | 8-10am only |
| Sunday | 9-11am only |

### Thread Mechanics
- Pinned reply with thread index boosts completion rate
- First tweet must hook HARD (3-5 lines max, curiosity gap)
- 5-10 tweets optimal. 3 = minimum viable. 15+ = only for massive accounts
- Each tweet must have standalone value — don't cliffhanger everything
- End with a strong closer + engagement prompt

### Hashtag Strategy
- 1-3 hashtags maximum
- Never in first tweet of thread (kills hook)
- Only if genuinely relevant to topic
- Ceiling effect: more hashtags = diminishing returns past 3

### Hook Formulas That Work
1. **Controversial claim** — "X is dead and here's why"
2. **Specific number** — "I made $47k in 3 weeks with no followers"
3. **Pattern interrupt** — "Everyone is wrong about Y"
4. **Second-person recognition** — "You don't need X, you need Y"
5. **Story setup** — "Last Tuesday I almost quit, then I discovered..."

## LINKEDIN ALGORITHM

### What the Algorithm Rewards
- **Comments** — especially thoughtful first-comment engagement
- **Saves** — LinkedIn weights saves heavily
- **Shares to personal network** — when someone shares your post
- **Topic authority** — consistency in 2-3 topics builds authority signal
- **Connection network amplification** — 2nd-degree connections see your posts
- **Early engagement velocity** (first 60 min critical)
- **Professional relevance** scoring

### What Gets Restricted
- Excessive hashtags (past 3-5 triggers spam filter)
- Engagement pods / fake engagement patterns
- Posting same content repeatedly
- Low-quality link posts (clickbait = reach penalty)
- Posting outside business hours (lower professional context)

### Optimal Posting Windows (AWST)
| Day | Best Times |
|-----|-----------|
| Monday | 7-9am (peak), 12pm |
| Tuesday | 7-9am (peak), 12pm, 5pm |
| Wednesday | 7-9am (peak), 12pm |
| Thursday | 7-9am (best day), 12pm (peak) |
| Friday | 7-8am only (lower — weekend prep) |
| Saturday | AVOID — minimal reach |
| Sunday | AVOID — professional context missing |

### First 3 Lines = Everything
LinkedIn shows only first 3 lines before "see more". These must contain:
- Hook (stop the scroll)
- Context (what this is about)
- Promise (what they'll get)

Never bury the value. Example structure:
```
Line 1: [HOOK] — Controversial claim or recognition trigger
Line 2: [CONTEXT] — Brief setup if needed
Line 3: [VALUE PREVIEW] — What they get if they read on
```

### Carousel Advantage
- Native LinkedIn carousel gets 3-5x more reach than image posts
- Each slide must have standalone value
- Title slide + conclusion slide = minimum 5 slides
- PDF upload quality matters — design quality signals authority

### What Performs
- Personal stories with business lessons
- Counterintuitive takes ("Stop doing X, do this instead")
- Data + insight (unique data performs extremely well)
- "I asked X people Y and here's what they said"
- Framework posts (numbered lists with substance)

## YOUTUBE ALGORITHM

### What the Algorithm Rewards
- **Click-through rate (CTR)** — thumbnail + title must stop the scroll
- **Watch time** — minutes watched, NOT views
- **Session duration** — how long people stay after clicking
- **Engagement** — likes, comments, shares, save
- **Audience retention graph** — consistency keeps people watching
- **Freshness signals** — newer videos get bumps, older decay
- **Subscriber vs non-subscriber ratio** — subs who watch signal trust

### Thumbnail Mechanics (80% of success)
- Faces with emotion = 30-40% higher CTR
- High contrast colours (red, yellow, bright blue)
- 3-4 elements maximum
- Text: 3-5 words, large font, white with black outline
- Expression > text on face thumbnails
- Wrong: busy backgrounds, small text, no face
- Right: subject + emotion + context in 2 seconds

### Title Formula
- **Format that wins:** "[Number] Things + [Outcome] + [Time/Effort if applicable]"
- **Formula:** "[Contrarian claim] — [Proof/Context]"
- **Length:** 50-60 characters optimal (SEO + display)
- **Power words:** Secret, proven, ultimate, simple, fast, free, new
- **CTR killer:** ALL CAPS, excessive punctuation, clickbait mismatch

### Hook Mechanics (First 30 Seconds)
Algorithm reads audience retention graph. First 30 seconds = survival zone:
1. **Problem stated** — "Most people are doing X wrong"
2. **Pattern interrupt** — "I didn't believe it either until..."
3. **Specific promise** — "By the end of this video you'll know..."
4. **Story setup** — "This changed everything when I found out..."

### Long-Form vs Shorts
| | Long-Form | Shorts |
|--|-----------|--------|
| Length | 8-20 min optimal | 30-90 sec |
| Algorithm | Watch time weighted | Completion rate weighted |
| Discovery | Search + suggested | For You page |
| Posted | 1-2x week max | Daily OK |
| Retention target | 50%+ average | 65%+ complete |

### Description Optimisation
- First 2 lines show in search results (embed keywords naturally)
- Structure: hook → timestamps → links → hashtags
- 200+ words for full algorithm benefit
- Include 3-5 timestamps (helps with sidebar placement)
- End with engagement question (boosts comments)

### Posting Cadence
- 1 long-form per week = minimum for algorithm loyalty
- 2-3 long-form per week = optimal growth zone
- Shorts daily = algorithm fresh signals
- Never go dark > 2 weeks (algorithm forgets you)

## NEWSLETTER / EMAIL ALGORITHM

### Deliverability (Gmail + Outlook)
- **Spam word triggers** — "free", "act now", "guarantee", "no risk", excessive caps
- **List quality** — spam complaints kill inboxing permanently
- **Authentication** — SPF, DKIM, DMARC required for serious sending
- **Engagement history** — Gmail tracks if recipients open, click, delete without opening

### Gmail Promotion Tab
- Gmail categorises bulk marketing as "Promotions"
- To land in Primary: personal sender reputation, high engagement
- Subject line and preview text must not look "markety"
- Send from consistent cadence (predictable = trustworthy)

### Open Rate Mechanics (Subject Line = 70%)
High-performing subject lines:
- **Curiosity gap:** "I almost didn't share this..."
- **Personal:** "Here's what I found on [topic]"
- **Specificity:** "3 things that changed my [outcome] this month"
- **Second-person:** "Your [problem] is worse than you think"
- **Urgency (real):** "Quick note before [event/changes]"

### Preview Text (Often Ignored = Free Real Estate)
- First 40-60 characters show in inbox preview
- Must complement subject line, not repeat it
- Never leave blank (email clients fill it with junk)

### Content Structure That Converts
1. **Personal opener** (2-3 sentences) — hook, warm up
2. **Value block** (main content) — 1-3 insights, substantive
3. **Curiosity bridge** — why this matters now
4. **CTA** — one clear action
5. **Personal closer** — signature, human touch

### Send Frequency
- Weekly = optimal (builds habit, avoids fatigue)
- Bi-weekly = minimum for list maintenance
- Never send more than 2x week (diminishing returns + unsubscribes)

## VISUAL CONTENT — CROSS-PLATFORM MECHANICS

### Thumbnail / Hero Image Principles
- **Faces + emotion** = universal stop-scroll trigger
- **High contrast** = readable in small sizes
- **3 elements max** = subject + context + emotion
- **Text:** 3-5 words, large, white on dark or black on light
- **Rule of thirds** = more dynamic than centre framing

### Quote Cards
- Quote must be substantive (1-2 sentences, punchy)
- Font: large, bold, high contrast
- Background: solid dark or branded colour
- Attribution: name + role (not company)
- Shareability: 1080x1080 = universal, works everywhere

### Carousel / Slide Image
- Consistent colour palette across slides
- One idea per slide (never crowded)
- Title slide = title + your name + visual hook
- Conclusion slide = "save this" + swipe indicator
- Each slide: headline + supporting visual/graphic

### Data Visualisation
- Simple > complex (readable at thumbnail size)
- Colour coding: max 3 colours
- Label directly on chart (no legend if possible)
- Source attribution = credibility signal

## POSTING CADENCE RULES (UNIVERSAL)

1. **Never flood** — algorithm interprets flood as spam signal
2. **Consistency > daily spikes** — 3x week every week > 7x in one week then nothing
3. **Optimal rest between posts** — minimum 2 hours X, minimum 24 hours LinkedIn
4. **Weekend taper** — reduce 30-50% Saturday/Sunday
5. **Time zone consistency** — pick your audience's prime window and hit it regularly
6. **Content type rotation** — alternate value/education, personal, engagement-bait
